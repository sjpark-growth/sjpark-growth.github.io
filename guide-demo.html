대시보드 설명서

다섯 화면을 언제 열고 · 무엇을 보고 · 어떻게 읽는지 한 장에 모았습니다. 실제 숫자는 각 화면에서 확인하세요.

  • DEMO실제로 쓰는 설명서를 옮긴 사본입니다. 문구는 그대로이고, 링크는 숫자를 바꾼 데모로 이어집니다.
  • 데모 없음쇼핑 인사이트 · PMC 트래커는 몰에서 받은 자료 · 실제 상품 가격이 중심이라 데모를 두지 않았습니다.

  • 이번 달 광고비가 계획대로 쓰이고, 쓴 만큼 팔리나 퍼포먼스 대시보드 설명 보기
  • 어제 무슨 일이 있었고 오늘 뭘 고칠지 — 질문 한 줄로 브리핑룸 설명 보기
  • 광고 늘리기 전, 재고가 버틸 수 있나 재고 신호판 설명 보기
  • 어떤 검색어 · 품목으로 넓힐지, 경쟁사는 어떤지 쇼핑 인사이트 설명 보기
  • 쿠팡이 왜 할인 차액을 매출에서 깎았나(PMC) PMC 트래커 설명 보기

각 화면 위쪽에도 같은 색 알약이 있어 바로 옮겨 갈 수 있고, 줄 끝 「대시보드 설명서」를 누르면 이 페이지로 돌아옵니다.

다섯 화면 공통 읽는 법

  • 1기준일부터

    기준일 자료 기준 도장으로 언제까지 자료인지 먼저 확인

  • 2덜 찬 숫자는 보류

    잠정 최신화 전 = 자료가 덜 들어옴. 판단은 다음 날

  • 3색 뜻은 화면마다

    빨강이 「넘침」일 수도, 「급함」일 수도. 아래 「어떻게 읽나」 참고

  • 4어려우면 표로

    표로 보기 엑셀로 같은 내용을 표로. 받은 파일은 회사 안에서만

화면별 설명

퍼포먼스 대시보드

운영 중인 모든 외부몰 매체의 광고비 · 매출을 우리 회사 기준으로 모은 성과판

먼저 볼 곳기간 소진 현황 「오늘의 한 줄」

화면 열기 ↗

언제 여나

  • 아침 점검 광고비가 계획대로 쓰이나
  • 넘치거나 남는 매체 찾을 때
  • 광고 수정 전후 근거가 필요할 때

무엇을 보나

  • 맨 위 선택 조회 월 · 브랜드 · 구분(외부몰 기본) · 왼쪽 메뉴로 구역 이동
  • 기간 소진 현황 오늘의 한 줄 · 요약 카드 · 월별 흐름
  • 매체별 성과 매체마다 쓴 돈 · 번 돈(줄 누르면 표)
  • 운영 구조 모니터 브랜드 키워드 의존도 · 매체 비중
  • ROAS/비용 추이 · 소진 페이스 효율 흐름 · 예산 쓰는 속도
  • 일별 효율 조회 날짜 · 요일 · 행사별
  • 품목별 · 캠페인별 성과 잘한 상품 · 광고 묶음

어떻게 읽나

  • 「오늘의 한 줄」 신호등 문장부터 (달 초 며칠은 판단 보류)
  • 매체 색 파랑 정상 · 주황 미소진 · 빨강 초과
  • 월별 흐름 세로 눈금 = 오늘까지 썼어야 할 지점, 점선 = 마감 예상
  • 브랜드 키워드 비중은 낮을수록 · 주력 품목 외 비중은 높을수록 좋음
  • 캠페인 옆 「수정」 딱지 = 그 광고를 고친 기록

몰 광고 화면보다 낮게 보여요 — 부가세 · 몰 수수료를 뺀 내부 기준입니다.

진행 중인 달은 합계 대신 하루 평균 · 구성비로 비교. 자료 기간 · 보정 내역은 맨 아래 「읽을 때 참고」.

브리핑룸 Beta

질문 한 줄을 쓰면 답 카드 한 장으로 정리해 주는 화면

먼저 볼 곳바로 카드(이슈 · 재고 · 쿠팡 권고안)

화면 열기 ↗

언제 여나

  • 아침에 어제 성과 빠르게 점검
  • 「왜 떨어졌지?」 이유가 궁금할 때
  • 오늘 광고 수정 방향을 정할 때

무엇을 보나

  • 몰 탭(맨 위) 전체 · 쿠팡 · 네이버 · 컬리 등으로 좁히기
  • 바로 카드 이슈 · 재고 · 쿠팡 권고안 — 누르면 바로 답
  • 왼쪽 칸 자주 묻는 질문 · 최근 질문 · 예정 계획(D-day)
  • 질문창 앞 질문의 몰 · 기간 · 품목을 이어받아 계속 질문

어떻게 읽나

  • 카드 순서 결론 → 핵심 숫자 → 차트 → 「이렇게 읽으세요」 → 할 일
  • 빨강 우선 · 주황 확인 · 초록 좋음 (급한 정도: 지금 · 오늘 · 이번 주)
  • 카드 맨 아래 「기준 —」 = 무엇으로 계산했는지
  • 챗봇(AI)이 아니라 정해진 계산 규칙으로 답함 · 질문은 페이지 밖으로 안 나감

상품 합계는 대시보드와 조금 다를 수 있어요 — 상품 자료로 따로 계산합니다. 순위 · 점유율은 참고만.

재고 신호판

품목마다 재고가 얼마나 버티는지, 그에 맞춘 광고 · 판매 조치를 보여 주는 화면

먼저 볼 곳오늘의 요약 카드

화면 열기 ↗

언제 여나

  • 매주 화요일 재고 계획(판매 · 생산 계획 회의) 자료 반영 뒤
  • 광고 늘리기 전 재고 확인
  • 재고 빠듯한 상품에 광고가 나가는지 볼 때

무엇을 보나

  • 오늘의 요약 판매중단 위험 · 발주 임박 · 드라이브 가능 · 소진 권장(누르면 그것만)
  • 재고 × 광고 트리 품목군 → 재고 신호 → 광고 현황 → 광고 조치
  • 품목군 목록 펼치면 맛 · 용량별 재고, 주별 출고, 판매처
  • 기준 시점 몇 주 뒤 재고를 미리 당겨 보기

어떻게 읽나

  • 품목군 신호 = 그 안에서 가장 먼저 떨어지는 맛 기준
  • 판매 조치 하 광고 줄이기 → 중 광고 멈추기 → 상 자사몰 · 쿠팡만 판매 → 금지 전 몰 판매중단 (조치 없음 = 회색)
  • 파랑 = 재고 많음, 빨리 팔면 좋은 소진 권장
  • 「광고」 배지가 붉으면 재고 빠듯한데 광고 중
  • 머리 경과일 배지가 경고색 = 재고 자료가 오래됨

판매처 막대는 출고 기준 — 실제 판매와 다를 수 있어요.

몇 주 뒤 추정은 입고 예정을 빼고 계산해 실제보다 빠듯하게 나옵니다.

쇼핑 인사이트 사내

몰 자료 · 광고 검색어로 시장 · 경쟁 · 고객을 보는 화면(탭으로 구분)

먼저 볼 곳키워드 인사이트 · 확장 권장 탭

사내 전용 · 데모 없음

언제 여나

  • 어느 몰 · 어떤 검색어에 광고를 더 쓸지 정할 때
  • 새 품목 확장 후보를 찾을 때
  • 주간 점검 · 기획 회의에서 경쟁 상황을 볼 때

무엇을 보나

  • 키워드 인사이트 검색어별 광고비 · 성과
  • 확장 권장 넓힐 만한 품목 · 몰별 빈자리
  • 쿠팡 프리미엄 데이터(시간대 · 유입 · 고객 · 경쟁 제품) · 광고 인사이트 · 카테고리 순위 · 경쟁
  • 네이버 스마트스토어 판매 분석 · 쇼핑 검색 순위 · 경쟁 · 검색/클릭 · 쇼핑단계
  • 컬리 · 이지웰 전체 광고주 속 우리 자리

어떻게 읽나

  • 탭마다 「자료 기준」 도장부터 확인
  • 돈은 쓰는데 전환율 낮은 검색어 → 광고보다 상품 페이지 먼저
  • 확장 권장 점수 = 살펴볼 순서일 뿐, 결론 아님
  • 쿠팡 「이탈」 = 우리 상품을 보고 다른 상품 구매 · 「인입」 = 반대
  • 네이버 가격 파랑 올림 · 빨강 내림 · 경쟁사 하루 판매량은 추정치

몰에서 받은 자료 — 회사 밖에 보여 주면 안 됩니다.

PMC 트래커

쿠팡 최저가 보장(PMC)으로 깎인 매출이 어떤 상품, 어느 몰 가격 때문인지 찾는 화면

먼저 볼 곳한눈에 → 이슈 상품코드

사내 전용 · 데모 없음

언제 여나

  • 평일 오전 몰 가격 자료가 다 들어온 뒤
  • PMC가 크게 난 날 원인 찾기
  • 다른 몰에 가격 조정 요청 근거가 필요할 때

무엇을 보나

  • 기준일 칩(맨 위) 날짜 선택 · 점 찍힌 날 = 갑자기 늘어난 상품 있음
  • 한눈에 그날 PMC · 전날/최근 평균 비교 · 원인 비중 · 그날 행사
  • 이슈 상품코드 원인 의심 상품과 몰별 가격
  • SKU 상세 · 가격 변동 · 수집 현황 상품별 상세 · 가격 바뀐 기록 · 자료 모인 날

어떻게 읽나

  • PMC = 다른 몰이 더 싸면 쿠팡이 값을 내리고 그 차액을 우리 매출에서 깎는 것
  • 원인 몰 = 몰 노출가가 쿠팡 기준가 +2% 안 · 쿠폰가 몰 = 노출가로 안 맞고 비로그인 쿠폰가가 ±2% 안
  • 회색 = 그날 가격 못 모음 (수집 현황에서 빈 날은 판정 불가)
  • 행사 추정 배지 유력 → 가능 → 참고 순으로 확실

몰 화면에 보이는 가격 기준 — 카드 · 간편결제 같은 결제수단 할인은 판정에 쓰지 않아요.

주말이나 PC가 꺼진 날은 자료가 비어 있어요.
